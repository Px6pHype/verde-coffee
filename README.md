# VERDE Coffee

Одностраничный сайт кофейни с интерактивным 3D-стаканом, меню, фактами о кофе и заказом через WhatsApp.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```powershell
npm.cmd install
npm.cmd run dev
```

Vite покажет локальный адрес в терминале.

## Проверки

```powershell
npm.cmd run test
npm.cmd run build

# Однократно перед первым браузерным тестом:
$env:PLAYWRIGHT_BROWSERS_PATH="$PWD\.playwright-browsers"
npx.cmd playwright install chromium

$env:PLAYWRIGHT_BROWSERS_PATH="$PWD\.playwright-browsers"
npm.cmd run test:e2e
```

Скриншоты главной, меню, формы и мобильной версии сохраняются в `artifacts/`.

## Публикация на GitHub Pages

1. Установи [Git для Windows](https://git-scm.com/download/win).
2. Создай репозиторий на GitHub, например `verde-coffee`.
3. Выполни команды в папке проекта:

   ```powershell
   cd C:\Users\s6426\verde-coffee
   git init -b main
   git add .
   git commit -m "VERDE coffee site"
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/verde-coffee.git
   git push -u origin main
   ```

4. На GitHub открой **Settings → Pages** и выбери источник **GitHub Actions**.
5. Workflow `.github/workflows/deploy.yml` соберёт сайт и опубликует его автоматически.
6. Адрес сайта: `https://ТВОЙ_ЛОГИН.github.io/verde-coffee/`.

Путь `/verde-coffee/` подставляется автоматически из имени репозитория. Если подключаешь собственный домен, замени в workflow переменную `BASE_PATH` на `/`.

## Ручная сборка

```powershell
npm.cmd run build
```

Готовые статические файлы находятся в `dist/`. Их можно разместить на HTTPS-хостинге. Сайт не требует серверной части, базы данных или API-ключей.

## Оптимизация и адаптация

- Шрифты Inter и Playfair Display подключены локально, разбиты по языковым подмножествам и загружаются только для используемых символов.
- 3D-сцена запускается в свободное время браузера и не блокирует первый экран.
- На мобильных используется облегчённый профиль 3D: меньше полигонов и меньшее разрешение текстуры при сохранении дизайна.
- На телефонах секции анимируются без дорогого blur целого экрана; hover-эффекты не «залипают» после касания.
- Поддержаны safe-area на iPhone, плавная прокрутка и `prefers-reduced-motion`.

## Заказ

Каталог, цены и номер WhatsApp находятся в `src/order.js`. Форма принимает напиток из каталога, имя и количество от 1 до 6. После проверки открывается `wa.me` с заполненным сообщением и рассчитанной суммой. Сайт не отправляет данные на свой сервер, не использует cookies и не сохраняет имя в localStorage.

## Безопасность

- Three.js поставляется локально в сборке, а не загружается со стороннего CDN.
- Внешние переходы разрешены только по сформированной HTTPS-ссылке WhatsApp и открываются с `noopener noreferrer`.
- Имя нормализуется и валидируется; HTML, ссылки и управляющие символы запрещены. Для всего DOM-контента используется `textContent`.
- ID напитка проверяется по встроенному каталогу; цена не берётся из DOM-атрибутов карточки.
- Количество строго ограничено целыми числами от 1 до 6.
- Настроены CSP, `nosniff`, `X-Frame-Options`, ограниченная Permissions Policy и защита opener.
- Есть fallback без WebGL, клавиатурное управление стаканом и поддержка `prefers-reduced-motion`.

Локальные security-заголовки задаются в `vite.config.js`. При публикации на другом хостинге их необходимо перенести в конфигурацию сервера. Meta-CSP уже находится в `index.html`, но политику `frame-ancestors` может применить только HTTP-заголовок сервера. Для рабочего сайта используйте HTTPS и не передавайте через форму платёжные или другие чувствительные данные.
